Analyze my existing application and **improve its visual design significantly**.

Make the application feel:

- Modern
- Clean
- Professional
- Elegant
- Polished
- Consistent
- Easy to use
- Visually balanced

Focus especially on:

- Better spacing and layout
- Stronger visual hierarchy
- Better typography
- More beautiful colors
- Consistent borders and border radius
- Better buttons and form controls
- Better cards and tables
- Better navigation
- Better icons
- Better empty/loading/error states
- Better hover and focus states
- Better alignment
- Better use of whitespace
- More polished micro-interactions where appropriate

### Responsive Design

The application **must be fully responsive**, especially on mobile.

Make sure the UI looks good and remains usable on:

- Mobile phones
- Tablets
- Laptops
- Desktop monitors
- Large screens

Do not simply shrink the desktop UI for mobile. Adapt the layout intelligently for smaller screens.

### Design Direction

Aim for a **premium modern SaaS/product UI**.

Use inspiration from high-quality modern products such as Linear, Vercel, Stripe, Notion, and other well-designed professional applications — but **do not copy them**.

Keep the design practical and avoid excessive decoration.

### Important

Before changing anything, inspect the existing application and understand its current design system.

Then improve the UI **incrementally** rather than unnecessarily rewriting everything.

Preserve:

- Existing functionality
- Business logic
- API behavior
- Routing
- Existing components where appropriate
- Existing design-system conventions

If something already works well, keep it.

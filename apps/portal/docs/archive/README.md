# Archive

Completed one-off task prompts, kept for history — not living documentation.
Each file is a status note pointing at the prompt that was originally used
to drive a coding-agent session, once its work has shipped.

When a root-level scratch `*.md` prompt's work is done, move it here
(`git mv <name>.md docs/archive/<slug>.md`) and add a short "Status:" note
at the top pointing to what implements it, instead of leaving it at the repo
root next to `README.md`/`AGENTS.md`.
